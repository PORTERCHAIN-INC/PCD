# Fleetbase modules (retired)

**Type:** CANONICAL · **Status:** retired

PorterChain owns dispatch, GPS, proof, and the day plan. Valhalla is the road cost. OR-Tools in `dispatch_engine` sequences one van.

There is no Fleetbase HTTP adapter, no Fleetbase console, and no `fleetbase_sync_jobs` / `fleetbase_sync_audit` tables.

See [ARCHITECTURE.md](ARCHITECTURE.md) and [INTEGRATIONS.md](INTEGRATIONS.md).
