Integrations fail quietly when every status looks the same in your ERP.

## Name the moments that matter

Dispatched, at pickup, exception, delivered, proof ready — each should trigger a different internal action.

## Pair webhooks with human exceptions

Automation routes the happy path. Ops still needs a clear escalation when a window stalls.

## Capacity first, pipe second

APIs do not create trucks. Quote vehicle class and windows before you wire the last status callback.
