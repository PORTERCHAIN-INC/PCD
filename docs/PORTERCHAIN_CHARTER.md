# PorterChain charter

**Type:** CANONICAL · **Verified:** 2026-09-15

PorterChain is **not** a courier, trucking company, dispatch/SaaS/fleet product, or marketplace.

PorterChain **is** a **Transportation Capacity Network** powered by intelligent software.

- **Transportation** — what customers pay for today (capacity: vehicle + driver)
- **Software** — engine for the network (not the SKU)
- **Network** — the moat

## Gate (before any feature or copy)

1. Which customer problem?
2. Who benefits? (merchant / driver / dispatcher / admin / receiver / partner)
3. Increases revenue, retention, trust, utilization, automation, efficiency, or satisfaction?
4. Strengthens moat? (network, relationships, data, trust, execution — not UI alone)
5. **Would we build this with only 10 paying customers?** If no → reject or postpone.
6. Makes PorterChain harder to replace?

Never optimize software in isolation. Always optimize the network.

Website 15-second test: what · who · why exist · why different · why trust · what next. Primary CTA: get a quote / request capacity. Phase 1 messaging only on customer paths.
