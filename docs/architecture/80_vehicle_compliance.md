# 80. Vehicle compliance (Phase 0, Ontario only)

## 0. Scope

This doc covers PorterChain as it actually operates:

- drivers use their own phones;
- vehicles are Ravi's Honda Civic and short-term rentals (Home Depot, U-Haul);
- there is **no owned fleet**;
- everything is in **Ontario only**.

**Filter (Ravi 29 Oct 2026, "whatever we need, just pick that").** Something is in only if it is (a) legally required in Ontario/Canada for us, (b) protects a claim, or (c) saves money.

**What we build.** **We do not build an operating system, firmware or kernel drivers.** It is the existing driver app (`apps/mobile-driver`, Expo/React Native) plus phone sensors (GPS, camera, clock), and server rules in the API.
