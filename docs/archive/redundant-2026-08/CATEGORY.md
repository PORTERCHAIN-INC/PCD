## Owned category name

**B2B last-mile orchestration software** — for regional shippers (50–500 shipments/week) in Ontario who need dispatch control without building an in-house logistics department.

## One-line pitch

The operating system for commercial logistics: quote → pay → dispatch → track → POD → invoice, with open APIs for ERP and commerce integrations.

## Audience boundaries

| Audience              | Surface                          | Message                                |
| --------------------- | -------------------------------- | -------------------------------------- |
| Merchant ops buyer    | Website `/platform`, `/business` | Orchestration + SLAs                   |
| Retail consumer       | Customer portal `:3004` only     | Book + track                           |
| Driver partner        | `/vehicle-partner`               | Structured routes, not gig marketplace |
| Investor / enterprise | ICP + case study + API docs      | Software margin, loop metrics          |

## Anti-positioning (do not say)

- "We are a courier company."
- "Cheapest same-day delivery."
- "AI-powered dispatch" (until Phase 2 model card shows prod lift).
