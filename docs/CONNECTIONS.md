# PorterChain connections (local · CI · production)

The laptop API reads **`apps/api/.env` only**. It does not load `env/.env` or Doppler.
Doppler project `pcd` / config `prd` is **production**. CI uses GitHub Actions secrets for deploy and placeholders for builds.

Check this Mac: `pnpm connections:check` (health only — never prints secrets).

## Not required (do not “fix” these)

| Name                    | Rule                                                                                                                                           |
| ----------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------- |
| NVIDIA                  | Lead Assist heuristic always works. NVIDIA only if `PORTERCHAIN_PHASE2_INTELLIGENCE=true` **and** a key is set. Keep Phase 2 off for dispatch. |
| Shopify                 | Boot does not need it. Keys matter when a merchant installs the app. App Store listing is an intentional skip.                                 |
| Zoho Calendar           | No API caller. Counts as on only when client id, secret, and refresh token are all set in **`apps/api/.env`**.                                 |
| Zoho SalesIQ            | Website must not load the widget (build guard).                                                                                                |
| Checkr                  | `CHECKR_MOCK=true` and `APP_ENV=local` is correct. No live key until the Checkr dashboard exists.                                              |
| Sentry                  | Off unless `SENTRY_DSN` is set. Optional in Doppler for later.                                                                                 |
| Lead webhooks           | Empty secret = channel dark. Turn on only when that ad channel goes live.                                                                      |
| Apple App Store Connect | Nothing in this repo reads `APPLE_ASC_*`.                                                                                                      |

## Local start (required stack)

```bash
pnpm docker:up
pnpm docker:up:routing
pnpm docker:fleetbase:up    # API :8000 + console :4200
pnpm clerk:sync             # from env/clerk.env; admin slots stay empty
pnpm connections:check
```

API: `pnpm dev:api` → `:8001`.
