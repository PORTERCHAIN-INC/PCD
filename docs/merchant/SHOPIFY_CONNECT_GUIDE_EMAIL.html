PorterChain Merchant guide

Shopify connection

Connect your Shopify store to PorterChain

Follow these steps from your merchant account so checkout can show PorterChain same-day capacity and new orders sync into your portal.

 

What you get after connecting

1. PorterChain rates at Shopify checkout (same-day local capacity)
2. New Shopify orders appear in PorterChain as bookings
3. Tracking and fulfillment updates flow back as deliveries complete
 

Before you start

Have these ready. Most merchants finish in under 10 minutes.

✓ An active PorterChain merchant account
✓ Access to sign in at merchant.porterchain.com
✓ Shopify store owner or staff permission to install apps
✓ Your warehouse / pickup address (saved in PorterChain)
 

Step-by-step: one-click connect

This is the recommended path for most merchants.

1

Sign in to PorterChain

Open the merchant portal and sign in with the account that should own this Shopify store.

Open merchant portal
2

Add your default pickup warehouse

PorterChain prices from your warehouse. If you have not saved a location yet:

  1. Go to Settings → Locations
  2. Add your warehouse address and set it as default
  3. Save

Open Settings →

3

Open Integrations → Shopify

In the portal, go to API / Integrations (or open the Shopify page). You will see the Shopify card.

Open Integrations →    Open Shopify page →

4

Enter your shop and choose pickup

  1. In Shop domain, enter your store (example: yourstore.myshopify.com)
  2. In Default pickup, select the warehouse from Step 2
  3. Click Connect with one click
5

Approve PorterChain in Shopify

You will be redirected to Shopify Admin. Review the permissions, then click Install / Approve. Shopify will send you back to PorterChain when the connection succeeds.

6

Confirm you are live

Back on the Shopify card you should see:

  • Your shop domain listed as Connected
  • A green status: Live — Shopify checkout can return PorterChain rates…
  • Your default pickup address shown under the shop

If you see Finish go-live, choose a pickup and click it once.

7

Verify with a test checkout

  1. In Shopify, start a test order with a delivery address in your PorterChain service area
  2. At shipping rates, confirm PorterChain Same Day (or similar) appears
  3. Complete the order (or a test order)
  4. In PorterChain, open Orders — the booking should appear with Shopify as the source

Open Orders →

 

Optional: connect with a custom Admin API token

Use this only if one-click is unavailable or your team prefers a custom Shopify app.

  1. In Shopify Admin, create a custom app with access to orders, fulfillments, and shipping (Admin API)
  2. Install the custom app and copy the Admin API access token (starts with shpat_)
  3. Optional: copy the app API secret key for webhook signing
  4. In PorterChain → Integrations → Shopify, click Use custom Admin API token instead
  5. Enter shop domain, paste the token (and secret if you have it), choose default pickup
  6. Click Connect custom app, then confirm the shop shows as Connected / Live

Never share your Admin API token by email or chat. Paste it only into the PorterChain connect form.

 

If something looks wrong

Connect is disabled / “pickup required”

Add a location under Settings → Locations, then select it as Default pickup.

No PorterChain rate at checkout

Confirm the Shopify card says Live, pickup is set, and the destination is inside your PorterChain service area. Then place a fresh checkout (cached rates can stick for a few minutes).

Order paid in Shopify but missing in PorterChain

Refresh Orders after 1–2 minutes. If it still does not appear, contact PorterChain support with the Shopify order number and shop domain.

“Shop already connected”

That store is linked to another PorterChain merchant. Ask your PorterChain contact to review ownership before reconnecting.
