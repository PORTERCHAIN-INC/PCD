# Config packages

Shared configuration for Porterchain apps.

| Location                                   | Contents                      |
| ------------------------------------------ | ----------------------------- |
| `shared/python/porterchain_shared/config/` | Python settings (API, worker) |
| `env/*.env.example`                        | Environment templates         |
| `packages/*/tsconfig.json`                 | TypeScript project references |

Frontend env examples live in each app (`website/env.example`, `apps/admin/env.example`, etc.).
